#  IdleRealms

A lightweight RPG Idle game engine built with **Spring Boot 3**. This project focuses on core combat mechanics, hero progression, and secure authentication.

## Core Features
- **PVE Combat System**: Turn-based battle logic including dodges, critical hits, and armor reduction.
- **Hero Statistics**: Dynamic stat calculation (STR, DEX, INT, CON, LUCK) influenced by equipment.
- **JWT Authentication**: Secure login and registration using HttpOnly cookies.
- **REST API**: Clean endpoints for game actions and account management.

##  Tech Stack
- **Java 21**
- **Spring Boot 3**
- **Spring Security (JWT)**
- **Spring Data JPA**
- **Lombok**
